## Description

Olive&ember is a responsive, five-page restaurant website. Visitors can
explore featured dishes, view the menu and prices, learn about the
restaurant, and fill in booking and delivery form layouts.

The forms are demonstrations and do not submit real requests.

## Features Implemented

- Five connected pages: Home, Menu, About, Booking, and Delivery.
- Shared navigation, header, and footer.
- Food images, dish cards, and a menu price table.
- Booking and delivery forms.
- External CSS and CSS variables.
- Flexbox, CSS Grid, and Bootstrap layouts.
- Hover and focus effects.
- Media queries for tablet and mobile screens.

## Technologies Used

- HTML5
- CSS
- Bootstrap CSS
